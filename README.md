# Метод Жуковца

Адаптивный информационный сайт о телесно-ориентированной терапии по методу
Руслана Жуковца.

## Локальный запуск

```bash
npm install
npm run dev
```

После запуска сайт доступен по адресу `http://localhost:3000`.

## Сборка

```bash
npm run build
```

Основные файлы интерфейса находятся в папке `app`, изображения — в `public`.
